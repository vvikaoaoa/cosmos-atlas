КОСМИЧЕСКИЙ АТЛАС — практическая работа № 4 (Git и LocalStorage)

КАК ЗАПУСТИТЬ САЙТ
1. Распакуйте ZIP-файл в отдельную папку.
2. Откройте папку Космический_атлас в Visual Studio Code.
3. Установите расширение Live Server, откройте catalog.html и выберите Open with Live Server.
   Можно попробовать открыть index.html двойным щелчком, но для надёжной работы
   LocalStorage рекомендуется запуск через Live Server (http://127.0.0.1:5500).
4. Перейдите в каталог и добавьте открытки в корзину.
5. Обновите страницу (F5): выбранные товары и сумма сохранятся.
6. Удалите товар, обновите страницу: удалённый товар не вернётся.
7. Очистите корзину или выполните демонстрационную оплату: после F5 корзина пустая.

ФАЙЛЫ
index.html — главная страница
catalog.html — каталог, фильтр, корзина
earth.html, mars.html, saturn.html — страницы планет
style.css — стили сайта
script.js — JavaScript и сохранение корзины в LocalStorage
images/ — изображения планет и маркера характеристик
GIT_ИНСТРУКЦИЯ.txt — пошаговая инструкция по публикации в GitHub
.git/ — локальная история Git с веткой и слиянием (если распаковщик сохраняет скрытые файлы)

ВАЖНО
Сайт работает без базы данных и без сервера оплаты: кнопка «Оплатить» учебная.
LocalStorage хранит данные в конкретном браузере для конкретного адреса сайта.
Имеющаяся Git-история — локальный учебный пример без связи с личным GitHub.
Перед сдачей необходимо опубликовать репозиторий из СВОЕГО аккаунта.
