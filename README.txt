КОСМИЧЕСКИЙ АТЛАС — Практическая работа № 3 (вариант 1, JavaScript)

Как открыть сайт:
1. Распакуйте ZIP-архив.
2. Откройте папку «Космический_атлас».
3. Запустите файл index.html двойным щелчком мыши.
4. Перейдите в «Каталог» — там работают фильтр и корзина.

Как проверить:
- Выберите «Газовые гиганты»: останется Сатурн.
- Выберите «Все планеты»: снова появятся три открытки.
- Добавьте две открытки: сумма изменится.
- Кнопка «Удалить» удаляет одну выбранную позицию.
- «Очистить корзину» удаляет всё.
- «Оплатить» при пустой корзине сообщает «Корзина пуста».
- «Оплатить» при непустой корзине показывает успешную покупку и очищает корзину.

Файлы:
index.html — главная страница
catalog.html — каталог, фильтр и корзина
earth.html, mars.html, saturn.html — страницы описаний
style.css — оформление всех страниц
script.js — логика фильтра, корзины и оплаты
images/ — локальные картинки

Сайт работает без интернета. Оплата учебная, реальные деньги не списываются.
Корзина хранится только в оперативной памяти страницы и очищается после её перезагрузки.
